## 2024-05-20 - Array Allocation and Iteration Overhead in Helper Functions
**Learning:** Frequent array instantiations and uses of declarative array methods like `.filter()`, `.flatMap()`, `.find()`, and `.map()` inside heavily accessed helper functions (`getAllFeatures`, `progress`, `getFeatureById`, etc.) create noticeable garbage collection pressure and CPU overhead in the core state tracking and TUI rendering pathways.
**Action:** In performance-critical areas that traverse the nested feature tree (e.g., `mission.milestones[].features[]`), prefer raw nested `for` loops and pre-allocated arrays where the maximum bounds are known, which can yield a 2x-10x+ improvement in those hot paths. Always be cautious not to duplicate logic when helper functions can just be reused if they are already optimized to be zero-allocation.
